- First build of this fork: installs as its own app, Minish Cap 3DS, next to the original port. Put the ROM in sdmc:/3ds/Minish Cap 3DS/.
- The GPU renderer now draws on the New 3DS too, not only on the Old 3DS.
- New bottom screen: icon tabs, clock, Wi-Fi, battery, smaller text and four colour themes (theme button in the tab bar).
- OPTIONS -> FRAMES: AUTO, LOCK 30 or NO SKIP, as in the Metroid ports.
- Beta builds have a DEBUG tab: performance switches that apply during play, SD log, perf recorder, GPU check.
